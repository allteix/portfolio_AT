Ce projet introduisait l’analyse de données grâce à l’utilisation du langage de programmation Python à travers un Notebook Jupyter. J’ai donc à nouveau exercé un 
poste de Data Analyst, cette fois pour une association luttant contre la faim dans le monde (FAO, ONU), et dont l’objectif était de réaliser une étude de grande 
ampleur concernant l’alimentation et plus particulièrement la sous-nutrition dans le monde.

Pour cela, j’ai appris à explorer et traiter les données qui m’ont été fournies afin de les rendre cohérentes et fiables pour ensuite effectuer les analyses qui
étaient demandées.
Je pouvais également ajouter les analyses supplémentaires qui me semblaient pertinentes pour le projet.

Vous pourrez trouver les 2 livrables produits dans ce dossier :
  - Le notebook Jupyter en langage Python contenant l’exploration des données et les analyses demandées. 
  - La présentation Powerpoint contenant  la méthodologie suivie, les résultats des analyses et les recommandations effectuées à l’association, utilisée lors de la
     présentation à l’oral du projet.
