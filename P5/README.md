Ce nouveau projet avait pour objectif de consolider les compétences en gestion de base de données avec le langage SQL.

Pour cela, j’ai à nouveau exercé un poste de Data Analyst pour un gestionnaire national d’agences immobilières qui souhaitait  modifier son modèle de base de données
lui permettant de collecter les transactions immobilières , puis effectuer une analyse du marché afin d’aider les agences régionales à mieux prévoir le prix de vente 
des biens et mieux accompagner leurs clients.

Je devais cette fois, créer, modéliser et interroger une base de données avec le langage SQL pour répondre à leurs besoins, mais en prenant en considération les 
règles de la 3ème Forme Normale (normes 3NF) et la réglementation RGPD (anonymisation des clients par exemple).

Vous pourrez trouver les 2 livrables produits dans ce dossier :
  - Le fichier Excel contenant le Dictionnaire des Données pour une meilleure compréhension et une normalisation du format des données présentes 
    dans la base de données.
  - La présentation Powerpoint contenant le contexte du projet, la méthodologie suivie, les analyses demandées et les recommandations effectuées, utilisée lors 
    de la présentation à l’oral du projet.
