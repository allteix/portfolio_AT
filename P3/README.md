Pour ce 3ème projet, j’ai à nouveau exercé en tant que Data Analyst mais pour une compagnie d’assurance habitation qui souhaitait regrouper les données concernant ses clients,
leurs biens et contrats d’assurances dans une base de données afin de faciliter leur activité et effectuer une analyse du marché des assurances habitations pour pouvoir mieux 
accompagner leurs clients à l’avenir.

Je devais donc apprendre et appliquer les bases de la création et gestion d’une base de données avec le langage SQL.

Vous pourrez trouver les 3 livrables produits dans ce dossier :
  - Le document technique contenant la méthodologie de création de la base de données.
  - Un document Word contenant les analyses effectuées et les résultats associés.
  - La présentation Powerpoint décrivant la méthodologie suivie et les résultats, utilisée lors de la présentation orale du projet.
